# Grill Me Skill (비판적 검증 & 논리 스토밍 스킬)

이 스킬은 사용자의 아이디어, 소스코드, 아키텍처 기획안을 심층 분석하여 방어적 논리 허점, 보안 취약점, 예외 처리 누락, 엣지 케이스를 무자비하고 날카롭게 공격하여 완벽한 품질로 끌어올립니다.

## 주요 검증 체크리스트

1. **논리적 허점 탐지**: 설계상의 모순이나 고려되지 않은 비즈니스 로직 구멍 지적.
2. **코드 예외 처리 리뷰**: Null Pointer, 타입 오류, 네트워크 타임아웃, 예외 처리 누락 점검.
3. **보안 및 스케일링 검증**: API Key 노출 여부, SQL Injection, 과도한 루프, 메모리 누수 탐지.
