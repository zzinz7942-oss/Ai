# Front-End Design Skill (UI/UX 반응형 디자인 구현 스킬)

이 스킬은 사용자가 구상한 UI/UX 기획이나 레이아웃 구상을 받아 현대적인 디자인 시스템(다크 모드, 글래스모피즘, 커스텀 폰트, 반응형 애니메이션 등)을 적용한 생산 수준의 프론트엔드 코드로 구현합니다.

## 디자인 가이드라인

1. **시각적 완성도**: 세련된 컬러 팔레트, 다크 모드, 반투명 효과(Glassmorphism) 적용.
2. **반응형 컴포넌트**: 데스크톱 및 모바일 화면에 반응하는 유연한 그리드와 폰트 크기 사용.
3. **인터랙티브 애니메이션**: 버튼 마우스 호버 효과, 모달, 탭 전환 애니메이션 적용.
