# Find Skill (AI 스킬 탐색 및 추천 가이드)

이 스킬은 사용자가 수행하려는 작업(코드 리팩토링, UI 개발, 데이터 분석, API 연동 등)의 맥락을 분석하고, 해당 작업에 가장 적합한 내장 스킬, 커스텀 스킬 및 도구를 탐색하여 추천합니다.

## 사용법 및 실행 지침

1. 사용자의 현재 작업 목표와 요구사항을 파악합니다.
2. 시스템 및 프로젝트에 등록된 사용 가능한 스킬 목록(.agents/skills/, builtin skills)을 스캔합니다.
3. 가장 효율적으로 문제를 해결할 수 있는 스킬을 추천하고 실행 가이드를 제공합니다.
